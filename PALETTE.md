# Dumpling Passport – Colour Palette!

Colours taken from our poster:

- Hex codes for models, materials, UI and particles so everything matches
- **Use:** In Godot, click any colour box -> type the hex code into the **Hex** field

## Utensils
| Name | Hex | Use |
|------|-----|-----|
| Steel | `#CFC8D3` | Pots, spoons, cutters, ladles (slightly lavender so it fits the palette) |
| Steel Shadow | `#9A90A0` | Darker metal parts, rims |
| Wood | `#D9A56B` | Rolling pin, wooden spoon, chopping board |

- **Metal materials:** Metallic 0.2, Roughness 0.4, toon diffuse and specular. 
- Keep metallic low so it doesn't go dark in passthrough.

## Rules of thumb
- Outlines and dark details use **Plum**, never black.
- Keep materials soft: Metallic 0, Roughness ~0.8, toon shading.
- Colours look a bit darker in 3D because of lighting; judge them in the art sandbox, not the colour picker.
